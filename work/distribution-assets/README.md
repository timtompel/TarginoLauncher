# Recursos de distribuicao

O pacote Fontes.zip de cada release contem avatar.png, banner.png, TarginoLauncher.ico, Plataformas/ e Controles/ com os creditos correspondentes.

Extraia os recursos de `work/distribution-assets` desse pacote para compilar os mesmos binarios. Nao incluir jogos, capas pessoais, sessoes ou catalogos da biblioteca original.

O avatar e banner sao a identidade Targino Social Media fornecida pelo proprietario. Artes e fotografias de terceiros conservam as licencas descritas nos arquivos CREDITOS. A disponibilidade dos fontes nao concede uma licenca unica sobre essas imagens.
